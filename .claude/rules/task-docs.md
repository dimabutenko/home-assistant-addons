# Task docs and handoff
- Task spec = `docs/tasks/NN-<slug>.md` with sections **Goal, Scope, Constraints, Verification, Definition of Done**. Small enough for one session.
- Statuses only: `TODO`, `IN_PROGRESS`, `DONE`, `BLOCKED`; keep `00-index.md` in sync in the same turn.
- `HANDOFF.md` holds: active task status, completed artifacts, decisions, blockers, ready-to-paste next-session prompt. Never claim a verification that did not run.
- Everything is written in English.
